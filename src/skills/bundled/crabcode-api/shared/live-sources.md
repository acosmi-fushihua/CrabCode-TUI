## When to Fetch

- Feature not covered in bundled docs
- API behavior doesn't match docs
- Pricing or model availability questions
- SDK version newer than v0.3.1
- WebSocket or real-time feature questions

## Tips

1. Prefer the Go SDK guide — most comprehensive reference
2. Use raw GitHub URLs for markdown files
3. API docs at acosmi.com may require JavaScript; prefer GitHub markdown
